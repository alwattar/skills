# Technical Seo

Audit crawlers/indexing, canonical URLs, redirects, robots, sitemaps, metadata, schema.org eligibility, hreflang, internationalization, pagination, duplicate content, and SSR/hydration. Validate robots and noindex specifically on CDN and preview domains. Check rendering and web performance with evidence before recommending changes. Avoid auto-generating unreviewed AI SEO spam, false structured data or location-landing-page doorway pages. Coordinate with privacy-review for external widgets and accessibility-audit for semantics.

## Deliverable
Include the intended outcome, prerequisites, concrete artifacts, measurable verification and open approvals; follow registered workflows.
