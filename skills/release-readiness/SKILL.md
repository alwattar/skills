# Release Readiness

Before releases or deployment changes, inspect approved scope, migration plan, environment configuration, secrets, feature flags, test evidence, security/privacy gates, observability, rollback/forward recovery, performance budgets, documentation and incident ownership. Distinguish verified checks from pending gates; do not deploy unless explicitly authorized. Output a Go/No-Go checklist with reproducible evidence, blockers and responsible owners. Never fabricate passing CI or production validation.

## Completion evidence
Report concrete files, tests, observed results and unresolved blockers. Follow the canonical registry and project-specific rules.
