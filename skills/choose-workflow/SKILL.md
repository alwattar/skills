# Choose Workflow

Read `registry/registry.yaml` and project policies. Explain which registered route best matches the task, why it fits, what safety gates apply and which skills will follow. Do not invent routes or maintain a second registry.
If actual execution is requested, delegate to `workflow-router`; unclear product goals first use `project-discovery`.
**Output:** recommended route with alternatives, assumptions and any approval gates.
