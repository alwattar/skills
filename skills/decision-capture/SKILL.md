# Decision Capture
Separate ADR candidates from product requirements, observed constraints, temporary choices, assumptions and open questions.
Only record durable rationale-backed decisions.

## Documentation language

Before creating or updating any repository engineering artifact, follow `.agents/workflow/rules/documentation-language.md`.

Follow the consuming project's approved documentation language (English by default). Preserve externally pasted ticket source text verbatim.

Do not apply this rule to localization files or explicitly requested translation artifacts.
