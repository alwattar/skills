# Dependency Audit

Use for dependency additions/upgrades and supply chain reviews. Identify direct/transitive impact, maintenance, license, provenance, lockfile integrity, malicious install hooks, vulnerable advisories and runtime compatibility. Don't run untrusted postinstall scripts on the host without appropriate isolation. Prefer supported patched versions, reproducible lockfiles and smallest viable dependency set. Record decisions and perform compatibility/tests. Do not present a vulnerability scanner pass as a security guarantee.

## Completion evidence
Report concrete files, tests, observed results and unresolved blockers. Follow the canonical registry and project-specific rules.
