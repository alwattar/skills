# Landing Page Optimization

Create or review a landing page using existing design system and approved brand messaging. Specify intended persona, offer, single primary conversion, content hierarchy, trust evidence, legal footer and contact/lead form. Ensure SEO and social metadata, mobile-first UX, accessibility, RTL/l10n as needed, Core Web Vitals budgets, anti-spam and consent-aware tracking. Never inject arbitrary HTML/JS or third-party pixels without review. Validate dynamic content and pricing freshness. Propose measurable A/B hypotheses, not aesthetic preference alone.

## Deliverable
Include the intended outcome, prerequisites, concrete artifacts, measurable verification and open approvals; follow registered workflows.
