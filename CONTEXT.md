# Unified Agent Skills terminology

- **Skill:** One focused, reusable capability with a SKILL.md contract.
- **Workflow:** An ordered combination of skills with optional-step conditions and gates.
- **Registry:** The single canonical mapping from skills to workflows, stages and next-step suggestions.
- **Review persona:** A bounded, read-only critical perspective; independence requires fresh context.
- **Project profile:** Consumer-owned configuration and constraints, not overwritten by shared updates.
- **Evidence:** Real observed test results or sourced findings, never unsupported claims.

Terminology and descriptions are maintained in `registry/registry.yaml` and the bilingual documentation.
