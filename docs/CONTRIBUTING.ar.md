# دليل المساهمة في المهارات الموحدة

## قبل إنشاء مهارة جديدة

ابحث في [السجل المركزي](../registry/registry.yaml) و[فهرس المهارات](SKILLS.ar.md)، وحاول تحسين مهارة موجودة أولاً. أنشئ مهارة جديدة فقط إذا كانت لها مسؤولية واضحة ومتميزة وقابلة للاختبار.

## أسماء المهارات وعقودها

استخدم أسماء إنجليزية ثابتة بصيغة kebab-case، واحفظ كل مهارة نشطة في `skills/<name>/SKILL.md` مع الاسم والوصف في مقدمة الملف. أضف وصفاً عربياً وإنجليزياً وشروط الاستخدام والمدخلات والمخرجات والمرحلة والمسارات والمهارات التالية إلى السجل. لا تكرر ترتيب مسارات العمل داخل المهارة.

## معايير الجودة

- صُن قرارات المالك والصلاحيات، ولا تقرأ أو تكشف أو تحفظ الأسرار.
- ميّز بين الحقائق المثبتة والافتراضات والأعمال المخطط لها والنصوص المنقولة.
- احترم حدود المشروع وقواعده وبوابات الموافقة.
- عرّف نتائج المهارة وآلية التحقق والفشل بوضوح.
- لا تدّعِ إجراء مراجعة مستقلة إذا لم تتوفر سياقات منفصلة حقيقية.
- حافظ على توافق التوثيق مع السلوك الذي اختبرته فعلاً.

## خطوات تطوير المهارات

1. عدّل المهارة أو أنشئها وأضف تعريفها للسجل.
2. عدّل المسار إذا كان ذلك ضرورياً، مع توثيق شروط الخطوات الاختيارية ومخاطرها.
3. أعد توليد الأدلة العربية والإنجليزية باستخدام `python3 scripts/generate-docs.py`.
4. شغّل `python3 scripts/validate-skills.py` و`python3 -m unittest discover -s tests -v`.
5. جرّب التثبيت في مشروع تجريبي وافتح Pull Request باتجاه فرع العمل الحالي.

## التوافق والمواد التاريخية

لا تحذف محتوى قديماً مميزاً قبل فحصه. احفظ المهارات المتقاعدة في `archive/`، وانقل الإرشادات المفيدة من النسخ المتكررة إلى المراجع الداخلية للمهارة الأساسية. احترم التراخيص والنسب المطلوبة عند استخدام النصوص الخارجية؛ أما الأفكار فتدمجها في نظامنا دون اعتماد تشغيلي خارجي.
